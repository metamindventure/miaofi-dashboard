

## 全新 3 套首屏动态背景方案 — 更丰富、更震撼、更 AI

### 问题诊断

之前的 3 个方案问题在于：
- 色彩单一（只用了 1-2 种颜色的渐变）
- 图案变化少（只有网格/光斑/条纹，缺少层次叠加）
- 动画节奏单调（只有一种速度和运动方式）

### 设计原则

新方案将遵循以下原则：
1. **多层叠加**：每个方案至少 4-5 层视觉元素，形成丰富的纵深感
2. **多色彩**：紫、青、蓝、品牌绿色交织，形成色彩变化
3. **多节奏动画**：快慢交替 — 缓慢漂移的光斑 + 中速旋转的光环 + 快速闪烁的粒子
4. **AI 仪式感**：让用户感觉"AI 正在为我工作"，充满期待

---

### 方案 A：神经网络脉冲（Neural Pulse）

**视觉概念**：像 AI 大脑在思考 — 中心是一个呼吸光环，向外发射脉冲波纹，背景是多色漂移光斑 + 微粒浮尘。

**层次构成（5 层）**：
1. **深层星云光斑**（3 个大型模糊光斑，紫/青/蓝，20-30 秒漂移动画，不透明度 0.3）
2. **中心脉冲光环**（从中心向外扩散的同心圆波纹，用 `box-shadow` + `scale` 动画，4 秒循环，不断扩散消失再生成）
3. **网格底纹**（极细的六边形/网格图案，不透明度 0.08，给背景添加纹理质感）
4. **浮动微粒**（用 CSS `radial-gradient` 模拟 20-30 个小光点，以不同速度缓慢漂移，有的亮有的暗）
5. **顶层光线扫描**（一条渐变色光线从左上角到右下角斜向扫过，6 秒循环）

**色彩**：品牌紫 + 青色 + 深蓝 + 少量品牌绿

**传达感受**：AI 正在思考和处理数据，像一个活的大脑

### 方案 B：量子数据涌流（Quantum Data Flow）

**视觉概念**：数据从四面八方汇聚到中心，像量子计算在处理海量信息 — 多方向流动的光线 + 中心能量聚合 + 粒子爆发。

**层次构成（5 层）**：
1. **多方向数据流线**（不只是从上到下，而是从四个角向中心汇聚的渐变光线带，用 `linear-gradient` + `mask` + 旋转角度实现，每组不同速度，8-15 秒循环）
2. **中心能量核心**（一个多色渐变的圆形光晕在中心缓慢旋转，用 `conic-gradient` + `rotate` 动画，颜色在紫/青/蓝/绿之间渐变过渡，12 秒循环）
3. **辐射光线**（从中心向外的放射状光线，用 `conic-gradient` 实现，极低不透明度，缓慢旋转）
4. **漂浮数据碎片**（多个小型矩形/菱形元素用 CSS 创建，在背景中以不同速度和方向漂移，有旋转动画）
5. **色彩脉冲叠加**（整体背景色温缓慢变化，通过 `hue-rotate` 动画让背景呈现微妙的色彩流动，30 秒循环）

**色彩**：品牌紫 → 青色 → 蓝色 → 回到紫色的循环渐变

**传达感受**：海量数据正在被量子级 AI 处理，强大且高效

### 方案 C：全息 AI 界面（Holographic AI Interface）

**视觉概念**：像科幻电影中的全息投影界面 — 多层旋转的圆弧/弧线 + 呼吸光点 + 动态渐变背景。

**层次构成（5 层）**：
1. **动态渐变底层**（用 `conic-gradient` 创建多色渐变，整体缓慢旋转 + 模糊，形成流动的色彩底层，60 秒循环）
2. **旋转弧线环**（3 个不同大小的半圆弧线，分别顺时针/逆时针/顺时针旋转，速度不同，用 `border` + `border-radius` 实现，颜色为紫/青/绿）
3. **脉冲同心圆**（多个同心圆从中心以不同间隔扩散，用 `scale` + `opacity` 动画，形成雷达扫描效果）
4. **数据节点网络**（用 CSS 绘制几个关键"节点"点（小光点），节点之间用极细的线连接，整体缓慢旋转/漂移）
5. **HUD 元素**（角落里的装饰性 HUD 元素 — 小方框、刻度线、圆弧，极低不透明度，增加科幻界面感）

**色彩**：紫/青/绿三色主导，加入少量暖色橙（warning 色）点缀

**传达感受**：未来科技全息界面，AI 正在全方位分析你的资产

### 技术实现

**修改文件**：
- `src/components/dashboard/backgrounds/CyberGridBg.tsx` → 重写为 NeuralPulseBg

- `src/pages/Index.tsx` → 更新切换器标签

**关键技术点**：
- 所有效果纯 CSS 实现，无需 Canvas 或 WebGL
- 使用 `will-change: transform` 和 GPU 合成层确保性能
- 所有动画使用 `transform` 和 `opacity` 以触发 GPU 加速
- 通过 `pointer-events: none` 确保不影响内容交互
- 多层 `mix-blend-mode: screen` 实现光效叠加
